## Contributing

All contributions are welcome, however keep in mind that we are following strict code styling. When contributing, be sure to follow guidelines and overall style of the project.

### Code

```bash
git clone git@github.com:LMNYX/am9client.git
cd am9client
pnpm install
pnpm tauri dev
```

For commits styling refer to <a href="https://www.conventionalcommits.org/en/v1.0.0/">Conventional commits guidelines</a>.

### Translation

As of now, please refer to `i18n` directory. Proper translation channel will be set up later.
